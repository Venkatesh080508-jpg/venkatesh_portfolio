# Project Hue

Create a clean, modern, minimal personal portfolio website.

IMPORTANT DESIGN DIRECTION:

- Do NOT use the common purple/blue AI portfolio aesthetic.

- No excessive gradients.

- No glassmorphism.

- No glowing effects or overly futuristic UI.

- Keep it clean, editorial, professional, and visually interesting.

- Use a warm off-white / cream background with black or very dark charcoal text.

- Use one subtle accent color such as burnt orange / terracotta for buttons, highlights, and small details.

- Use plenty of whitespace.

- Typography should feel modern and premium, with bold headings and clean readable body text.

- The overall design should feel like a carefully designed creative developer portfolio rather than a template.

VISUAL STYLE:

Use:

- Warm cream/off-white background

- Dark charcoal/black typography

- Burnt orange / terracotta accent

- Thin subtle borders

- Large typography

- Generous spacing

- Rounded corners, but not excessive

- Subtle hover animations

- Smooth scrolling

- Small micro-interactions

- Clean image placeholders

Avoid:

- Purple

- Blue gradients

- Neon colors

- Glassmorphism

- Excessive shadows

- Excessive animations

- Floating glowing blobs

- Generic AI-dashboard styling

- Huge amounts of text

Make the website fully responsive, especially for mobile.

The content should be easy to edit later. Keep all placeholder text clearly marked with brackets such as [YOUR NAME], [PROJECT NAME], [DESCRIPTION], etc.

Use a professional modern font pairing and maintain strong visual hierarchy.

The final result should feel minimal, creative, clean, and premium.
